     - 既有 JSON 流程零行为变化：非 blob 请求 `responseType` 为空、`data` 非 Blob，新分支短路跳过，原 `body.code` 判定逻辑逐字保留（仅把两个回调改为 async 以支持 blob 读回，返回值语义不变）。
